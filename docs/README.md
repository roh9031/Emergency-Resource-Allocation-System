# docs/

- `proposal/` — LaTeX proposal (`proposal.tex`). Each member sets `\MemberAtrue` / `\MemberAfalse` and compiles their own PDF.
- `API.md` — request/response examples for every endpoint (create in iteration 2).
- `decisions.md` — short log of design decisions and why (create now; add an entry whenever you change the model or an algorithm).
- `figures/` — final plots and screenshots for the report.
- `report/` — final paper (create in iteration 4).
